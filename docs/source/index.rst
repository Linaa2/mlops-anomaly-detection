MLOps Anomaly Detection
=======================

Pipeline MLOps de condition monitoring pour systèmes hydrauliques —
classification de l'état des composants (cooler, valve, pompe, accumulateur)
à partir de séries temporelles capteurs.

**Dataset :** `UCI Hydraulic Systems <https://archive.ics.uci.edu/ml/datasets/Condition+monitoring+of+hydraulic+systems>`_
